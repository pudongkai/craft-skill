# 已知问题清单

开发循环里出现过的问题、表现和对应的规则。遇到新问题时按同样的格式往后加，并在 SKILL.md 的“硬性规则”里补一条对应规则（如果需要）。

| 编号 | 问题 | 表现 | 对应规则 / 机制 |
| --- | --- | --- | --- |
| F1 | 做完一个阶段就停下 | 阶段完成后输出总结，问“是否继续下一阶段？”，然后结束回复 | 规则 R1；Stop hook 在还有未完成阶段时拦截停止 |
| F2 | 完成后不标记 | 代码写完了，技术方案里还是 `[ ]` 或 `[~]`，下次恢复时重复开发或漏掉验证 | 规则 R2；单轮流程第 5 步“在方案里标记”；Stop hook 的提示里要求先补标记 |
